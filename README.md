# نُسُغ

**أرشيف نصوصٍ للقراءة والدراسة — نواتُه كنز أبي الهيثم محمد درويش، مسؤول قسم المقالات بموقع طريق الإسلام.**

موقعٌ ثابت (static) يَعرض مقالاتٍ مُسترجَعةً من أرشيف موقع طريق الإسلام، تُعرض بإذن كُتّابها، والحقوق لأصحابها. لا قاعدة بيانات ولا خادم حيّ — مجرّد صفحات HTML خفيفة، سريعة، تعمل في أي مكان.

---

## كيف يعمل؟

ادفَعْ بياناتٍ جديدة → يَبني **GitHub Actions** الموقعَ وينشُره وحده. لا خطوة يدويّة.

```
data/                 ← مقالات العربية           (articles.jsonl)
data-<lang>-<section>/← مواد اللغات الأخرى        (مثل data-fr-article/articles.jsonl)
build_site.py         ← المولِّد: data/ → site/
build_author.py       ← صفحة كاتبٍ مُفصَّلة (اختياري)
islamway_articles.py  ← المُسترجِع من أرشيف Wayback
.github/workflows/    ← خطّ البناء والنشر التلقائيّ
```

> `site/` لا يُدفَع — يُولَّد آليًّا في كل نشر (مُدرَج في `.gitignore`).

## صيغة البيانات

كل سطرٍ في ملفّ `.jsonl` مادةٌ واحدة:

```json
{"id": 7014, "author": "أبو الهيثم محمد درويش", "title": "طوق النجاة", "categories": ["..."], "body": "نصّ المقالة ..."}
```

الحقول المدعومة: `id` (رقم)، `author`، `title`، `body` (إلزاميّة)، و`categories` / `tags` / `date` / `source_url` / `wayback_ts` / `author_url` (اختياريّة).

## تحديث المحتوى

1. ضَعْ ملفّات `.jsonl` الكاملة في `data/` و`data-<lang>-<section>/`.
2. ادفَعْها:
   ```bash
   git add -A && git commit -m "تحديث المحتوى" && git push
   ```
3. يَبني Actions الموقعَ وينشُره خلال دقائق. تابِع التقدّم في تبويب **Actions**.

## البناء محليًّا (اختياري)

```bash
python3 build_site.py      # يُنتج مجلّد site/
```
يعمل على بايثون 3.6 فأحدث، بلا أي اعتماديّات خارجيّة.

## النطاق المخصّص (nosogh.org)

بعد شراء النطاق من مُسجِّلٍ مستقلّ (Cloudflare Registrar مثلًا):

1. أضِفْ سجلّات DNS عند المُسجِّل:
   ```
   A      @   185.199.108.153
   A      @   185.199.109.153
   A      @   185.199.110.153
   A      @   185.199.111.153
   CNAME  www <المستخدم>.github.io
   ```
2. في **Settings ← Pages ← Custom domain**: اكتب `nosogh.org`، وفعّل **Enforce HTTPS**.

> حين تُضيف النطاق، يُنشئ GitHub ملفّ `CNAME` في فرع النشر تلقائيًّا؛ لا حاجة لإضافته يدويًّا ما دام النشر عبر Actions.

## الحقوق والأمانة

- النصوص محفوظة من موقع **طريق الإسلام**، وتُعرض بإذن كُتّابها، والحقوق لأصحابها، ومصدرُ كلّ مادةٍ مذكورٌ في صفحتها.
- نواة المشروع مقالات **أبي الهيثم محمد درويش** المنشورة بإذنه ونسبتها إليه.
- هذا عملٌ تطوعيّ وقفيّ، منفصلٌ تمامًا عن أي نشاطٍ تجاريّ.
